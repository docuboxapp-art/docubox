# Docubox PDF fonts

These font files are bundled for deterministic server-side PDF generation.
They must be embedded before the PDF is signed.

- `Inter-Regular.woff`: Inter 400, SIL Open Font License 1.1.
- `Inter-Bold.woff`: Inter 700, SIL Open Font License 1.1.
- `RobotoMono-Regular.woff`: Roboto Mono 400, SIL Open Font License 1.1.

The corresponding license texts are stored beside the font files. The fonts
were sourced from Fontsource packages version 5.3.0.
